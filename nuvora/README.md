# NUVORA

個人利用向けのスマートフォン用タイマーです。
ゲーム中に横に置いて使うことを想定しています。
1分または3分の短時間カウントダウンに特化しています。

## 仕様

以下は既存タイマー仕様です。

### 深海水時計タイマー 仕様書

## 1. 概要

スマートフォンでゲーム中などに使用する、1分・3分の短時間カウントダウンタイマー。

画面全体を「深海の水時計」に見立て、時間の経過に合わせて画面下部から水がゆっくり上昇する。

* スマートフォン専用
* 縦向き固定
* 1画面完結
* 画面遷移なし
* 外部ライブラリなし
* HTML / CSS / JavaScriptで実装
* PCでの利用は想定しない

---

## 2. 基本仕様

### 時間設定

選択できる時間は2種類のみ。

* `1 MIN`
* `3 MIN`

初期状態は `1 MIN`。

時間表示はカウントダウン形式。

例：

```text
1:00
0:59
0:58
...
0:01
0:00
```

---

## 3. 画面構成

1画面のみ。

概念イメージ：

```text
┌────────────────────┐
│                    │
│                    │
│                    │
│       0:42         │
│                    │
│                    │
│~~~~~~~~~~~~~~~~~~~~│
│████████████████████│
│████████████████████│
└────────────────────┘

       1 MIN   3 MIN

       START   RESET
```

実際のUIでは、水が画面全体を覆うように表示される。

タイマー数字は常に中央付近に表示し、水の上でも下でも十分なコントラストを確保する。

---

## 4. ビジュアルデザイン

### テーマ

**深海 / Water Clock**

暗い深海の中で水が満ちていくイメージ。

### 背景

非常に暗い青緑系。

例：

```text
#0B1719
```

※最終的な色味は実装時に調整可能。

### 水

深い青緑〜ティール系。

例：

```text
#176B73
```

### 透明感

水には透け感を持たせる。

完全なベタ塗りではなく、背景がわずかに透けて見える程度。

### 水の動き

時間経過に合わせて、画面下から上へ**スーッと上昇**する。

派手なアニメーションにはしない。

水面のみ、ごく弱く揺れる。

* 大きな波：なし
* 激しい揺れ：なし
* 泡：なし
* 粒子：なし
* 光の演出：なし

全体としてシンプルで落ち着いた見た目にする。

### 水量

残り時間ではなく、**経過時間に応じて水が増える**。

```text
開始       0%
25%経過   25%
50%経過   50%
75%経過   75%
完了      100%
```

完了時には水が画面全体を満たす。

---

## 5. フォント

タイマー表示は、スマートフォンから少し離れて見ても読みやすい、太めでしっかりしたサンセリフ系フォント。

数字を最重要情報として扱い、高い視認性を確保する。

---

## 6. ボタン

画面上に表示する文字は**すべて英語**。

### 時間選択

```text
1 MIN
3 MIN
```

### 操作

```text
START
STOP
RESET
```

### 操作の意味

#### START

* WAITING状態 → カウント開始
* PAUSED状態 → 一時停止した位置から再開

#### STOP

* RUNNING状態 → 一時停止

#### RESET

* WAITING状態 → 選択中の時間に戻す
* RUNNING状態 → 選択中の時間に戻す
* PAUSED状態 → 選択中の時間に戻す
* COMPLETED状態 → 選択中の時間に戻す

---

## 7. 状態管理

タイマーは以下の4状態を持つ。

### WAITING

初期状態。

* 初期選択：`1 MIN`
* 時間表示：`1:00`
* 水量：0%
* `1 MIN` / `3 MIN`：選択可能
* `START`：使用可能
* `RESET`：使用可能

---

### RUNNING

カウントダウン中。

* 時間表示：残り時間
* 水：0% → 100%へ上昇
* `1 MIN` / `3 MIN`：変更不可
* `STOP`：使用可能
* `RESET`：使用可能
* 画面スリープ防止：有効

---

### PAUSED

一時停止中。

例：

```text
1:32 → STOP → 1:32
```

* カウント停止
* 水の位置もそのまま保持
* `1 MIN` / `3 MIN`：変更不可
* `START`：使用可能
* `RESET`：使用可能
* `START`で停止位置から再開

---

### COMPLETED

カウント終了後。

* 時間表示：`0:00`
* 水量：100%
* 水は100%状態を維持
* 完了音を再生
* 完了音は数秒後に自動停止
* `RESET`：使用可能
* 時間選択：変更不可

`RESET`するとWAITING状態へ戻る。

---

## 8. 時間選択ルール

### WAITING

`1 MIN` / `3 MIN`を自由に変更可能。

例：

```text
1 MIN → 3 MIN
```

すると表示も、

```text
1:00 → 3:00
```

に変更。

### RUNNING / PAUSED / COMPLETED

時間変更不可。

時間を変更したい場合は、

```text
RESET → 1 MIN / 3 MINを選択
```

とする。

---

## 9. RESETの仕様

RESETは常に「現在選択されている時間」に戻す。

例：

```text
3 MINを選択
↓
START
↓
残り1:24
↓
RESET
↓
3:00
```

1 MINを選択していれば `1:00` に戻る。

RESET後はWAITING状態となり、再びSTARTできる。

---

## 10. カウント方式

タイマーの正確性は `setInterval()` の呼び出し回数に依存させない。

実際の経過時間を基準に計算する。

例：

```text
elapsed = currentTime - startTime
remaining = duration - elapsed
```

これにより、

* ブラウザの処理遅延
* バックグラウンド移行
* 一時的な処理停止

などが発生しても、実際の経過時間に基づいてタイマーを進行させる。

表示更新には `requestAnimationFrame` または適切なタイマー処理を使用する。

---

## 11. バックグラウンド時の動作

ゲームなどを使用しながらの利用を想定する。

ページがバックグラウンドになっても、タイマーそのものは実時間ベースで進行する。

### バックグラウンド中

* カウント継続
* 実際の経過時間を維持
* 完了時の音は再生しない

### 復帰時

バックグラウンド中に時間切れになっていた場合、

```text
0:00
水100%
COMPLETED
```

として表示する。

復帰した瞬間に遅れて完了音を鳴らすことはしない。

---

## 12. 画面スリープ防止

このページを開いている間は、可能な限りスマートフォンの画面が消えないようにする。

用途は、ゲームをプレイしながらタイマーを画面に表示しておくこと。

そのため、**RUNNING中だけでなく、このページを開いている間は画面スリープ防止を維持する**。

Web標準の Screen Wake Lock API を利用する。

ただしiOS / Safari側の制約などにより、OSによる画面消灯を完全に保証するものではない。

ページがアクティブになった際には、必要に応じてWake Lockの再取得を試みる。

---

## 13. 完了時の演出

カウントが `0:00` になった瞬間：

1. 水が100%まで到達
2. タイマー表示が `0:00`
3. 完了音を再生
4. 完了音は数秒後に自動停止
5. COMPLETED状態を維持

完了時に大きな画面遷移や派手なエフェクトは行わない。

---

## 14. 完了音

短い自転車の通知ベルのような音。

イメージ：

```text
チリン♪
```

特徴：

* 短い
* 耳障りすぎない
* ゲーム中でも気づきやすい
* 数秒以上鳴り続けない

音源を使用する場合は、利用条件を確認したローカル音声ファイルを使用する。

またはWeb Audio APIでベル風の音を生成する。

音量はブラウザ / iPhone側の音量設定に従う。

---

## 15. 音声のバックグラウンド制御

バックグラウンド中にタイマーが終了しても音を鳴らさない。

例：

```text
START
↓
ゲームを開く
↓
1分経過
↓
タイマー内部では完了
↓
音は鳴らさない
↓
タイマー画面へ戻る
↓
0:00 / 水100%を表示
```

## 21. 完成イメージ

「深海の中に大きな数字が浮かび、時間が経つにつれて下から静かに水が満ちていく」タイマー。

ゲーム中にスマートフォンを横に置いても、

**残り時間が一目で分かること**

を最優先する。

**数字・水量・操作ボタンの分かりやすさを優先する。**
